# シートのデータ同期（DailyCSVSync）を23時に変更する手順

データの流れは「サロンボード → **DailyCSVSync**（Apps Script）→ スプレッドシート → ダッシュボード」です。
DailyCSVSync の実行時刻は **Google アカウント内の Apps Script トリガー**で決まっているため、
変更は Google の画面から行います（1回だけ・約2分）。

## 手順

1. 対象のスプレッドシートを開く → メニュー「**拡張機能**」→「**Apps Script**」
   （DailyCSVSync が別プロジェクトにある場合は <https://script.google.com> から該当プロジェクトを開く）
2. 左メニューの時計アイコン「**トリガー**」をクリック
3. DailyCSVSync（同期を実行している関数）の行の右にある**鉛筆アイコン（編集）**をクリック
4. 「時間ベースのタイマーのタイプ」を「**日付ベースのタイマー**」、
   「時刻を選択」を「**午後11時〜午前0時**」に変更
5. 「**保存**」

- 鉛筆アイコンが無く編集できない場合：その行をゴミ箱アイコンで**削除** →「**トリガーを追加**」で
  同じ関数・「時間主導型」・「日付ベースのタイマー」・「午後11時〜午前0時」を選んで保存します。
- 予約データと会計明細が**別のスプレッドシート**（別プロジェクト）の場合は、両方で同じ手順を行ってください。

## 知っておくと安心なこと

- Google の仕様で「何時何分ちょうど」は指定できず、実行は**23時台のどこか**になります。
- 同期が終わると `sheet-update-stamp.gs`（設定済みの場合）が「データ更新日時」を自動で書き込み、
  ダッシュボードの「データ更新 ◯月◯日 ◯◯:◯◯ 時点」表示も23時台になります。
- ダッシュボードは**開くたびに最新を読み込みます**。開きっぱなしの端末（店頭タブレット等）も、
  同期完了後の**毎日0:15に自動で再読み込み**します。
- もし同期が Apps Script ではなく PC のツール等で行われている場合は、そのツール側の
  スケジュール設定を23時に変更してください。
